Files a person adds when a source cannot be downloaded automatically.
See ../README.md ("When something breaks"). Adding a file here on main re-runs
the monthly comparables workflow.

- `Luzon_Batangas.pdf` - BDO's PDF, saved from bdo.com.ph
- `<source>.rows.json` - a source's table entered by hand (bdo, bpi, securitybank)

`bdo.rows.json` (as of 10 Oct 2026) was read from BDO's PDF with
`sources/bdo.js` in a browser, to seed the first snapshot.
